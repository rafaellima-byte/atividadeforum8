Atividade Pratica - Testes em Node.js 
Projeto desenvolvido para praticar testes automatizados unitarios e de rotas em uma API Node.js utilizando Express, Prisma ORM e Vitest.

Tecnologias: Node.js, Express, Prisma ORM, Vitest e Supertest.

Como Executar o Projeto:

Instalar as dependencias executando npm install.

Configurar o banco de dados executando npx prisma migrate dev --name init.

Executar os testes automatizados executando npm test.

Gerar o relatorio de cobertura de codigo executando npm run test:coverage.
